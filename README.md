# DH101 — Critical Making Portfolio

Hello, DH! This site documents my critical making and reflections throughout this semester in Digital Humanities 101.

## 🌸 About the Website

This portfolio is built with a modern pastel color aesthetic, full dark mode support, and an interactive tabbed interface designed to mirror the course structure:

- **🏠 Home**: Overview of the critical making journey, syllabus roadmap, and quick links.
- **🛠️ Makes**: Documentation for all weekly hands-on critical making artifacts, process notes, and AI attribution.
- **💭 Reflections**: Weekly critical reflections responding to core course inquiries on AI, culture, labor, and society.
- **📄 Pages**: Foundational course pages including *About Me*, *How I Use AI*, *Sustainability & Ethics*, and *Accessibility*.
- **🤖 AI Log**: Interactive log tracking prompts, AI outputs, and scholarly decisions.
- **🎓 CV**: Curriculum Vitae highlighting academic coursework, technical methods, and critical making projects.

## 🚀 Viewing the Site

1. **Locally**: Simply double-click `index.html` or open it in any web browser. It is fully self-contained and requires no server or build process.
2. **GitHub Pages**: When published to GitHub Pages, the site will be accessible at:  
   `https://adelinebohi.github.io/DH101/`

## 📁 Repository Structure

```
DH101/
├── index.html            # Main site entry point
├── css/

├── js/

```
